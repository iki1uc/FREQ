# FREQ – S-Ebene · iki1uc

## Zweck
FREQ ist das Signal-Modul des 6E-Würfelsystems.
Es transportiert Frequenzen, Impulse und Schwingungen zwischen
body (D3), ANKER (D4), API (D5) und der META-Ebene (HELP).

## Struktur
- NAME: FREQ
- ROOT: iki1uc
- SYSTEM: 6E
- MODUL: FREQ
- DIM: S (Signal)

## Rolle
FREQ ist die Impuls- und Frequenzachse des Systems.
Es verbindet Energie (D3) mit Übergang (D5) und META.

## TMP-Läufer
SYQ stabilisiert Übergänge zwischen API und META.

## Regeln
- FREQ ist kein D0–D5 Modul.
- FREQ liegt in der S-Ebene (Signal).
- FREQ darf die 6E-Matrix nicht verändern.
